# هوش‌مانیتور پرو

داشبورد فارسی (راست‌چین) برای نظارت لحظه‌ای کریپتو، طلا، نفت و فارکس. بدون سرور؛ فقط فایل‌های استاتیک.

## اجرا
- ساده: `index.html` را کنار `style.css` و `script.js` باز کنید.
- برای PWA/نصب روی گوشی و حالت آفلاین باید روی HTTP سرو شود، مثلاً:
  `python3 -m http.server 8080` و سپس `http://localhost:8080`

## منابع داده (رایگان و بدون کلید)
| داده | منبع |
|---|---|
| قیمت و ۵۰ ارز برتر، دامیننس، USDT/USDC | CoinGecko |
| کندل و استریم لحظه‌ای | Binance (data-api.binance.vision) |
| Funding، Open Interest، لیکوییدیشن، نسبت لانگ/شورت | OKX |
| انس طلا و نقره | gold-api.com |
| DXY (فرمول ICE) و جفت‌ارزها | Frankfurter (ECB) |
| ترس و طمع | alternative.me |
| MVRV، ورود/خروج صرافی | Coin Metrics Community |
| هش‌ریت و درآمد ماینر | blockchain.info |
| نهنگ‌ها | mempool.space (اختیاری: Whale Alert با کلید) |
| اخبار | RSS: CoinDesk، The Block، Cointelegraph |
| نرخ دلار/تومان | Nobitex (USDT/IRT) یا نرخ دستی |
| تقویم اقتصادی، نفت، شاخص‌ها | ویجت‌های TradingView |

## محدودیت‌های نسخه بدون سرور
- سفارش واقعی صرافی ممکن نیست (CORS و امنیت Secret)؛ همه سفارش‌ها آزمایشی (Paper) هستند.
- وب‌هوک TradingView آدرس عمومی لازم دارد؛ پیام آلارم را می‌توان در صفحه پیست و اجرا کرد.
- اتصال MT4/MT5 از طریق اکسپرت تولیدشده (`.mq4` / `.mq5`) است.
- هشدارها و پیام تلگرام فقط وقتی صفحه باز است ارسال می‌شوند.
- SOPR و کیف‌پول‌های قدیمی فقط در منابع پولی (Glassnode/CryptoQuant) موجودند.
- API نوبیتکس ممکن است خارج از ایران در دسترس نباشد؛ در این حالت نرخ دستی استفاده می‌شود.
- کلیدها (صرافی، OpenAI، تلگرام) فقط در localStorage همان مرورگر ذخیره می‌شوند.

این ابزار توصیه مالی نیست.
